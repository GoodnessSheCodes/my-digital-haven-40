# My Professional Hub

Create a modern, responsive, and professional personal website, the website must include a Home page 👤 About Me section

💻 Technical and soft skills

📂 At least 3 projects with descriptions and technologies used

🎓 Education

📜 Certifications

💼 Work experience (if applicable)

📞 Contact section with your email, GitHub, and LinkedIn

📄 Downloadable CV ,these are the Technical Requirements

Responsive on desktop, tablet, and mobile devices

Professional and modern UI/UX

Easy navigation it should have a bar on top with the buttons that lead to all available sections
